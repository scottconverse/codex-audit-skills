Codex Audit Skills

Evidence-first audit workflows for Codex: quick PR checks, full release-gate packets, and a compatibility alias for legacy audit-team prompts.

Read the README Open the manual

Three Skills

audit-lite

Fast single-pass review for small PRs, narrow branches, and dev report verification.

audit-full

Deep multi-role audit packet with executive summary, deep dives, sprint punchlist, and watchlist.

audit-team

Compatibility alias for older Claude-style prompts that should now route to audit-full.

Install

.\scripts\install.ps1

Restart Codex after installation. The skills are copied into ~/.codex/skills.

Audit Contract

Evidence
Findings cite files, commands, screenshots, workflows, or runtime behavior.
Severity
Blocker, Critical, Major, Minor, and Nit have explicit definitions.
Action
Every finding has a concrete fix path and blast-radius notes where needed.
